# Publication scope

## Public scope

This repository contains methodological and software materials only.

Public materials may include:

- research specifications;
- data contracts;
- acquisition and transformation code;
- statistical diagnostics;
- evaluation code;
- public integrity tests;
- technical documentation.

## Excluded materials

The public repository intentionally excludes:

- third-party raw data;
- processed empirical datasets;
- empirical result tables;
- publication figures;
- research-result manifests;
- post-result numerical regression locks;
- proprietary HilmarCorp model assets;
- credentials and infrastructure secrets.

## Research status

This repository is research infrastructure.

It does not constitute investment advice, portfolio management, execution services or a recommendation concerning any financial instrument or crypto-asset.
