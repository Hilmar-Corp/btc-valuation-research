# Reproducibility

This public repository exposes the methodological and software layer of the Bitcoin valuation research project.

Empirical datasets, result tables and publication artifacts are intentionally excluded.

## Verification

Run:

    python -m pytest -q
    python tools/audit_public_repository.py

The public controls verify the repository boundary, required governance documents, configuration validity and Python-source integrity.

## Empirical reproduction

Reproducing empirical analyses requires users to obtain the relevant source data directly from the respective providers under their applicable terms.

The public repository provides research methodology and software without redistributing those datasets.

## Separation from research results

Empirical results are distributed separately through HilmarCorp research publications where appropriate.

They are not part of this Apache-2.0 software repository.
