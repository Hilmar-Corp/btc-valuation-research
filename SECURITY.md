# Security policy

## Scope

Security reports should concern the software, workflows or repository
configuration contained in this project.

Do not publish credentials, private keys, API tokens, infrastructure details or
other sensitive information in a public issue.

## Reporting

Potential security vulnerabilities should be reported privately to HilmarCorp
through an appropriate private communication channel.

## Research repository

This repository is research infrastructure and is not a production trading,
custody or execution system.
